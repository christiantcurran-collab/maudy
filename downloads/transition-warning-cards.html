⏳ Transition Warning Cards

Help prepare for upcoming changes

How to Use:

  • Print and laminate all three cards
  • Show cards in sequence before transitions
  • Start with 5-minute warning, then 2-minute, then 1-minute
  • Helps reduce anxiety about unexpected changes
  • Use with timer so child can track remaining time
  • Especially helpful for transitions from preferred activities
