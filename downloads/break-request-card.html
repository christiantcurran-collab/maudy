Break Request Card

How to Use:

  • Print and laminate this card
  • Child can hand card to teacher/adult when feeling overwhelmed
  • Teaches non-verbal communication of needs
  • Prevents escalation by allowing early break
  • Return card when ready to come back
🛑
I NEED A BREAK
Please excuse me

I'm feeling overwhelmed and need:

✓ A quiet space
✓ Time to calm down
✓ A few minutes alone

I will return when I'm ready

💡 Tip for Teachers: Honor this card immediately. A 5-minute break can prevent a 50-minute meltdown!
